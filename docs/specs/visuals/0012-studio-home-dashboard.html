Spec 0012 · enhancement

Studio home dashboard: what needs you today, then a compact status overview

Proposed 2026-10-22 Scope feature 28 · Studio slice 7 Tracer Bullet · Alpha

Summary

The studio home page at /studio changes from a plain list of status lines into a dashboard that answers "what needs me today" first. A row of four counts (inquiries, contracts, retention, public export) sits on top, each with its three oldest items, then three small status bars for clients, contracts, and projects, then a quiet footer for database and storage health.

It reads only tables and helpers that already exist, so there is no migration, no new environment variable, and no new library.

Decision

Rebuild the signed in page.tsx as a server component that runs one guarded read per signal plus the overview and health checks in parallel, contains each failure to its own section, and draws the bars with plain Tailwind elements.

Options compared

Option 1

Fix in place

  • Smallest change
  • Still a wall of equal weight text
  • Every item two clicks away

Not chosen: it fails the brief, nothing visual and no next action.

Chosen · Option 2

Attention first, server rendered

  • Answers what needs you first
  • Reuses retention and drift logic, never disagrees with those pages
  • No migration, one commit to revert
  • About ten queries per load

Chosen: useful at a glance and keeps one guarded server render.

Option 3

Client side with API routes

  • Widgets refresh on their own
  • New guarded routes for the leak check
  • Chart library and spinners for three bars

Not chosen: more surface and code for data that changes a few times a day.

Option 4

Precomputed summary table

  • One query per load
  • Every write path must update it
  • Migration and backfill for no measured problem

Not chosen: premature optimization with a fragile duty.
